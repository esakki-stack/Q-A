# Local article data

No newspaper archive, uploaded article, or private dataset is included in this repository. Use only text you own or have permission to process. Store any local/private documents under `data/private/`, `data/uploads/`, or `data/outputs/`; those directories are excluded from Git. Do not commit copyrighted newspaper archives, personal information, generated indexes, databases, or other private content.

The current active application accepts article text directly. This directory is not an ingestion corpus and the app does not build a RAG index.
